# 01 · PBR 基础

[返回目录](README.md) · [下一篇：BRDF 模型](02_BRDF_Models.md)

## 1. PBR 的含义

PBR（Physically Based Rendering）用物理规律约束材质与光照：反射受角度影响，材质不能凭空产生能量，灯光与反射在线性空间相加。同一材质换到别的灯光环境后，应尽量保持可信的材质特征。

PBR 不等于「必须写实」，也不等于「打开 Metallic 就完成了」。风格化角色也能使用这套参数与光照基础，再有意识地改造明暗和高光。

## 2. BRDF：描述材质怎样反射光

BRDF 是双向反射分布函数：从 `L` 方向来的光，向 `V` 方向反射的能力有多强？

$$
f_r(L,V)=\frac{dL_o(V)}{dE_i(L)}
$$

`L_o` 是出射辐亮度，`dE_i(L)` 是来自 L 附近一小片方向范围的入射辐照度。更具体地，`dE_i(L)=L_i(L)·max(N·L,0)·dω_L`，所以分母里已经包含投影余弦和方向范围，而不只是入射辐亮度 `L_i`。BRDF 的单位为 `sr⁻¹`。

它描述材质响应，**不包含**当前灯的颜色、距离衰减或场景阴影。单个尖锐高光的 BRDF 数值可以大于 1；是否守恒要看对半球的积分，不能只看某一点。

最终单光源颜色的计算骨架：

```text
材质 BRDF × 光色与强度 × max(N·L, 0) × 距离/角度衰减 × 阴影可见性
```

BRDF 与像素颜色的联系见 [05](05_Rendering_Equation.md)。

## 3. 光照方向与点乘

所有方向必须在同一坐标空间，并归一化。

| 符号 | 定义 | 常见用途 |
| --- | --- | --- |
| `N` | 着色点的单位法线 | 表面朝向 |
| `V` | 表面 → 相机 | 观察方向 |
| `L` | 表面 → 光源 | 入射方向的约定 |
| `H` | `normalize(V + L)` | 能将 L 镜面反射到 V 的微表面法线 |
| `NoL` | `saturate(dot(N,L))` | Lambert 余弦与 G |
| `NoV` | `saturate(dot(N,V))` | G 与可见半球判断 |
| `NoH` | `saturate(dot(N,H))` | D |
| `VoH` | `saturate(dot(V,H))` | 直接镜面 Fresnel F |

当向量归一化且 `H` 有效时，`VoH = LoH`。`N·V` 不能随意代替直接光中的 `V·H`。`L + V` 接近零时，半角向量不稳定，需要做保护。

## 4. 反射的两部分

- **漫反射**：光进入介质后散射再离开，Lambert 用一个与出射方向无关的近似描述它。
- **镜面反射**：表面界面的定向反射。即使粗糙表面的高光很宽，它仍然属于镜面项。
- **金属**：本笔记的不透明金属模型没有体漫反射，Base Color 用于有颜色的镜面反射。
- **非金属**：通常同时有漫反射与界面镜面反射；塑料并非「没有高光」。

## 5. 能量约束与互易性

互易性要求交换 `L` 与 `V` 后，BRDF 相同：

$$f_r(L,V)=f_r(V,L)$$

能量约束要求固定入射方向时，反射能量不超过入射能量：

$$\int_{\Omega^+}f_r(L,V)(N\cdot V)\,d\omega_V\le1$$

这里固定 L，对所有出射方向 V 积分；限制逐波长成立，RGB 近似中按通道检查。公式用同一个宏观表面法线定义半球和余弦。实际渲染若用法线贴图改变着色法线，还需另外考虑它与几何表面法线不一致造成的能量及阴影边界问题。

这些条件用于检查模型整体。简单地令 `kD = 1 - F` 是实用近似，不能据此宣称整套分层模型严格守恒。GGX 单次散射还会漏掉微表面间多次反射的能量。

## 6. 为什么要在线性空间计算

Base Color 颜色贴图通常按 sRGB 存储，采样时解码到线性空间；金属度、粗糙度、AO、法线是数据，不应按颜色解码。在线性空间完成光照与混合，再交给显示输出流程编码。不要在 BRDF 末尾手动 `pow(color, 1/2.2)`。

学习微表面假设可继续阅读 [PBRT 微表面理论](https://www.pbr-book.org/4ed/Reflection_Models/Roughness_Using_Microfacet_Theory)。本笔记采用常见实时近似，具体 D/F/G 见 [03](03_Cook_Torrance_DFG.md)。

## 7. 微表面：用统计解释粗糙度

宏观看起来平整的表面，微观上仍有不同朝向的小面片。光滑表面的小面片方向比较集中，反射也集中；粗糙表面方向更分散，反射会铺到更宽的方向范围。

Shader 不会真的创建这些小面片，而是用 D 描述方向分布、用 G 近似相互遮挡，再用 F 计算界面的反射比例。因此 Roughness 不是给颜色乘一个“粗糙系数”，而是改变镜面反射的方向分布与遮蔽。

Normal Map 则描述当前着色点可分辨的方向细节。它与粗糙度都影响高光，但处在不同的尺度，不能互相替代。

## 8. 从 PBR 到代码的职责划分

| 计算内容 | Shader 中的职责 |
| --- | --- |
| 材质颜色、金属度、粗糙度 | 从常量或贴图得到材质输入 |
| N、L、V、H 与点乘 | 为 BRDF 提供几何关系 |
| 漫反射与镜面 BRDF | 计算材质对该方向光的响应 |
| 光色、NoL、衰减、场景阴影 | 将材质响应转换为单光源贡献 |
| 多灯、间接光、自发光 | 组合当前片元的线性 HDR 颜色 |
| 曝光、色调映射、显示编码 | 将光照结果显示到屏幕 |
